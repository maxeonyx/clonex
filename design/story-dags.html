CloneX's merge uses the replaced commit e3 as the base for tools/tb. The umbrella's side is exactly e3, so tools/tb simply becomes e3′, with no conflict (Q-S7b). The trailer is recorded in M, so every machine maps M down the same way: M is e3′ (Q-S2e). It names commits, not labels (D1).

A plain git merge uses ρ(e1) as the base. Both sides changed the ledger since e1, differently, so it conflicts in .test-status.json, a file the umbrella never touched. And a plain lens would map M down to a new tb commit merge(e3, e3′), which would put the bad history back into tb if anyone published it.
